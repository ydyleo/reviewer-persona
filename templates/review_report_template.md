# 代码检视报告模板

> 本模板严格遵循 `references/review-output-format.md`。字段名不得自行改动。
> `{...}` 为占位符，生成时替换为实际值。

```
═══════════════════════════════════════════════════════════════
                    代码检视报告
═══════════════════════════════════════════════════════════════
检视Commit: {commit_id}
评审分身: {persona_name}（{persona_w3}）
代码变更文件: {file_count} 个{（摘要：file1, file2, ...）}
═══════════════════════════════════════════════════════════════
```
